# Сервис генерации резюме и портфолио с экспортом в PDF

Учебный полнофункциональный проект для генерации резюме с мгновенным превью и экспортом в PDF.

## 🚀 Возможности
- **Структура данных**: контакты, опыт работы, образование, навыки, проекты.
- **Интерактивный интерфейс**: мгновенный предпросмотр (Live Preview) при вводе данных.
- **Валидация полей**: проверка обязательных полей (ФИО, Email, Телефон, Профессия).
- **Выбор шаблонов**: переключение между 2 визуальными макетами (Современный и Классический).
- **Экспорт в PDF**: генерация многостраничных PDF прямо на клиенте с точным сохранением стилей и шрифтов (`html2pdf.js`).
- **Бэкенд на Node.js / Express**: REST API для сохранения и загрузки шаблонов / данных резюме.

## 🛠️ Запуск проекта

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск сервера
```bash
npm run dev
# или npm start
```
Сервер запустится по адресу: `http://localhost:5000`

### 3. Запуск веб-интерфейса
Откройте файл `client/index.html` в браузере (или используйте расширение Live Server в VS Code).
